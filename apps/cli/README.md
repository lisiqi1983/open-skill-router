# CLI

The CLI is the first user-facing surface. It should remain thin and delegate
parsing, scoring, caching, security, and installation behavior to packages.

Initial commands:

- `skillrouter index`
- `skillrouter index-source`
- `skillrouter recommend`
- `skillrouter inspect`
- `skillrouter install`
- `skillrouter list`
- `skillrouter update`
- `skillrouter pin`
- `skillrouter serve-mcp`
